🖐️ Numi — Hand-Based Math Interaction System

An interactive learning tool that uses real-time hand tracking to turn abstract math into a physical, visual experience.

⸻

📌 Overview

Numi is a web-based interface that leverages camera-based hand tracking to help users — especially children — understand math through gesture and physical interaction.

Instead of relying on abstract symbols, users can use their fingers to represent numbers, making math more intuitive and accessible.

“We aim to reduce cognitive load and help children with learning disabilities such as dyscalculia ‘see’ the math they are doing.”  ￼

⸻

🎯 Problem

Traditional math learning:
	•	Relies heavily on abstract symbols
	•	Causes cognitive overload
	•	Leads to disengagement, especially for learners with dyscalculia  ￼

Many existing tools remain:
	•	Screen-based
	•	Non-interactive
	•	Not physically intuitive

⸻

💡 Solution

Numi bridges the gap between:
👉 Abstract numbers
👉 Physical understanding

By:
	•	Mapping finger gestures → numerical values
	•	Providing real-time visual feedback
	•	Turning math into a tangible interaction

⸻

✨ Key Features
	•	🖐️ Real-Time Hand Tracking
Detects hand and finger positions using the camera
	•	🔢 Gesture-to-Math Mapping
Converts finger positions into numbers and operations
	•	⚡ Instant Feedback
Visual (and later audio) feedback reinforces learning
	•	♿ Accessible Design
Built for children and users with dyscalculia

⸻

🧠 Why This Works

Research shows:
	•	Finger-based learning improves number understanding
	•	Physical interaction reduces cognitive load
	•	Gesture-based learning increases engagement  ￼

Fingers act as:

A natural bridge between physical movement and mathematical thinking  ￼
